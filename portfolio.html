02 / 响应式设计

为不同屏幕安排内容

  • 空间桌面把中文命题与折面并列；手机把标题、完整折面和个人身份组织成纵向顺序。图形与正文各有自己的阅读空间。
  • 比例字号、行高、图形尺寸和位置分别调整。中文主标题保持两行，英文品牌文字降低权重，内容整体没有被等比例压小。
  • 入口768px仍保留完整导航；760px以内折叠为目录。菜单可由键盘操作，Escape可关闭，导航目标保留顶部补偿。
  • 动效有限固定区间与原生滚动共存。前进、后退使用同一个进度状态；系统或站内减少动效时提供静态阅读。
03 / 技术实现

静态生成与托管

原生 HTML、CSS 与 JavaScript。资料集中在 JSON，模板生成根目录 HTML，适配 GitHub Pages 静态托管。访问者无需安装依赖，也不需要后端或数据库。

首页至个人介绍以同一折面形成信息结构；Python项目展示真实工具在示例文件上的分类、预览、确认与日志。项目筛选、邮箱复制和原生详情展开保留独立入口。

网站使用 GitHub Pages 静态托管，源码与版本记录保留在 GitHub。

04 / 验证

布局与交互验证

静态检查验证资源、相对路径和锚点；浏览器验证桌面、平板、手机的实际构图，检查正反向、导航、无脚本与减少动效。演示的关键位置与真实首页的测量结果对照，避免看似流畅却失真的布局。

测试结果与环境记录随实现保留。浏览器模拟不能代替真实手机、其他浏览器和人工读屏验收。
