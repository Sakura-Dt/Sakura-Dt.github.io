02 / PYTHON AUTOMATION

让整理文件，先有预览.

一个不需要第三方依赖的 Python 命令行工具。先看清文件将去哪里，再决定是否执行。

下载 Python 脚本 ↓使用说明 →

第一版能做什么

  • 按扩展名将第一层文件归入图片、文档、压缩包、媒体或其他目录。
  • 默认只读预览；指定 --apply 并输入 MOVE 才执行。
  • 同名文件不覆盖，跳过隐藏文件、子目录和符号链接。
  • 逐项记录已移动的相对文件名，保存在目标目录的日志中。

在测试目录体验

下载脚本，准备一个名为 sample-files 的测试目录，放入几份测试文件。需要 Python 3.12，Windows 可将下面的 python3 换成 py。

python3 file_organizer.py ./sample-files

# 检查预览后，再执行并输入 MOVE 确认
python3 file_organizer.py ./sample-files --apply

这个工具在自己的电脑上运行，网页不会读取或上传你的文件。

实现思路

用 pathlib 扫描目录，把“生成计划”和“执行计划”分开。执行时重新核对文件是否变化，通过同文件系统的硬链接再删除原路径，避免覆盖已存在目标。测试使用临时目录验证取消、重名、文件变化和链接等情况。

边界与后续计划

第一版不递归、不提供自动撤销，也不支持不具备硬链接能力的文件系统。执行期间不要同时修改目标目录。中途失败时可能已经移动部分文件，需要核对目录和日志；它不是事务式整理工具。

后续可根据真实使用反馈增加可验证的恢复流程与自定义分类规则。
