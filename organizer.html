项目 01 / Python 文件整理助手

文件整理助手

本地运行的命令行工具：先预览分类计划，输入 MOVE 后执行。

预览→确认→移动
01 / 工具行为

分类与执行分开

使用 Python 标准库 pathlib 扫描目录第一层的普通文件，按扩展名安排到 images、documents、archives、media 或 others。生成计划与执行计划使用不同函数。

  • 默认只显示去向，不创建目录、不移动文件。
  • 指定 --apply 后，仍需输入大写 MOVE 确认。
  • 已有目标不覆盖；隐藏文件、子目录和符号链接跳过。
  • 已完成的移动逐项记录到目标目录的 .organizer-log.jsonl。
02 / 本地运行

在本地试用

需要 Python 3.12，无第三方依赖。下载脚本后，创建 sample-files 测试目录，放入几份无关紧要的文件。Windows 可将 python3 换成 py。

01 / 预览，不移动
python3 file_organizer.py ./sample-files
02 / 核对预览后执行
python3 file_organizer.py ./sample-files --apply
提示时输入 MOVE，其他输入会取消。

03 / 使用限制

当前限制

目前不递归、不自动撤销。通过同文件系统硬链接建立目标，再删除原路径，以避免覆盖已有目标；文件系统需要支持硬链接，没有跨文件系统复制模式。

执行前会重新核对源文件。执行期间不要同时修改目录。它不是事务：中途失败时，部分移动可能已经完成。请核对目录和日志；日志写入失败时最后记录可能不完整。

恢复流程与自定义分类仍是后续方向，尚未实现。

04 / 测试

测试覆盖哪些情况

测试覆盖预览无副作用、取消确认、重名目标、源文件变化、目录与符号链接等情况。测试仅操作临时目录，不整理开发电脑的真实文件。
