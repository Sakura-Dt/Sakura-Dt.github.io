| 方向 | 概念与母题 | 配色、字体 | 图形、动态 | 文案与滚动 |
| --- | --- | --- | --- | --- |
| A 折向 / FORM IN THE MAKING | 平面经过折叠，成为有用途的结构；对应需求成为作品 | 纸白 #f1eee6 / 朱红 #ee492d / 群青 #273cce / 淡黄 #e9edac；压缩英文大字、中文无衬线、少量衬线斜体 | 原创六面折体、折痕、视窗、文件纸页；扇形旋转、平面展开、宽高重排、沿计划移动 | 明确动作与边界，“文件动身前，去向先落定”；四个进度场景加两段阅读/收束 |

选择 A：它最能以同一种几何规则覆盖身份、响应式页面、文件操作和联系入口，而不依靠人物插画、版权素材或虚构项目。B 的持续路径容易重复，C 的遮罩对正文阅读和手机要求更苛刻。A 的折面不仅是装饰：它会组织层次、说明版式转变、显示文件去向，并在站点标识中收束。

## 系统规则

- 以一条斜向折痕和三角平面定义母题。六面主体不是随机线条；同一面在蓝色材料场中变成折痕，在 Web 场中变成重排视窗，在 Python 场中变成纸页折角。
- 大英文承担画面质量，中文承担语义。英文不把中文重复一遍；辅助字号与正文有明确层级。首屏 FORM / IN THE / MAKING 与“把问题，折成形”形成两套读法。
- 字体修正后：本地 Archivo（英文正文与75%宽度的展示字）配合 Noto Sans SC（中文400–700字重），取消 Impact 与 Georgia 混搭。字重与CJK字距统一；两个压缩子集随站点分发，不依赖外部字体服务，缺字仍有系统回退。来源与许可见 assets/fonts/README.md。
- 六个主场景改变密度与主色：纸白红蓝海报 → 群青材料 → 纸白红色网页封面 → 淡黄文件剧场 → 炭黑阅读 → 朱红联系海报。
- 动作表达过程：折体旋转、折痕展开、网页收窄、文件对齐与执行。正文没有入场隐藏，不用批量淡入替代设计。
- 所有图形为自绘 SVG / CSS。不使用官方视频画面、Logo、角色、音乐与游戏 UI 资产。无网络字体、图像或动画运行依赖。

## 工程与阅读边界

四段演出用自然滚动与 position:sticky。桌面额外停留 560–760px，舞台始终占视口，不以空白撑长页面。滚动使用 requestAnimationFrame 合并并缓存测量；图形用约75ms的指数跟随吸收离散滚动步进，再映射到各元素错开的局部阶段。不接管滚轮；收敛后的同位置状态在正反向一致，停住后控制器休眠。

手机取消整场固定，正文顺序阅读，保留轻量进度变换与文件步骤按钮；没有隐藏移动端内容。prefers-reduced-motion 与站内开关取消固定区间，保留完整静态图文。低核心数/省流量环境使用无 pin 模式。没有 JavaScript 时仍可阅读、使用链接与原生 details，筛选不是内容入口的前置条件。
