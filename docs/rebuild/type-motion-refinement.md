# 字体与动效修正

2026-10-30。针对用户反馈“字体违和、动画僵硬”进行的后续实现。修正前版本是 f9458fa，修改在 codex/type-motion-refinement 分支；没有推送、部署。

## 字体问题与修改

原版把 Impact 极粗展示字、Georgia 斜衬线、默认中文黑体放在同一构图里。字重、宽度、笔画和中文标点比例不协调；系统字体也导致设备之间的实际效果不稳定。

现在使用本地 Archivo 与 Noto Sans SC 变量字体：英文展示字采用75%宽度和650字重，正文采用正常宽度；中文主标题600字重，正文400。取消斜衬线与伪粗体，统一中英文字形逻辑；中文标题行高1.22，字距回到更自然的范围。首屏、蓝色材料场、项目预览、详情页、结尾和邮箱都同步调整。

两份WOFF2共158,552 bytes，含真实400–700字重，经过字符子集压缩，保留SIL OFL许可和上游来源。预加载避免布局过晚替换。网页没有运行时外部字体请求。完整加载预算由旧版无字体的150 KiB更新为含本地字体的256 KiB；实测首页约223 KiB，详情页各约184 KiB。来源与更新方法见assets/fonts/README.md，字体生成脚本仅作可选维护，不是运行依赖。

## 动作问题与修改

原版直接将滚动位置写入图形，离散滚轮会形成逐格跳动。多项运动采用相同节奏，文件同速直线平移，确认印记依赖缩放突入。

- 视觉进度以约75ms的指数响应跟随真实滚动（手机58ms），只平滑图形，不修改原生滚动。不引入无休止弹簧或滚轮接管。
- 局部阶段用端点速度、加速度均为零的五次曲线，折角、文字、视窗与纸页错开开始和完成。快慢和停顿由内容过程决定。
- 开场取消硬矩形擦入，改为小幅位移与旋转的落定；六面图形保持共享顶点展开，取消大幅反向旋转。
- 蓝色折痕的四角与中心分阶段回正，文字随后归位。
- 网页视窗先回正，再收窄重排；大字慢一拍移动，次要标注平缓退出。
- 文件逐张沿弧线移动，各自旋转、缩小、抵达后显示目标文件名；确认印记轻量出现，不再突然由小变大。
- 桌面流程按钮平滑滚到对应状态；手机按钮也经过同一跟随控制器，避免直接跳变。
- 停止滚动后精确收敛，控制器停止申请新帧。反向最终状态与正向一致。减少动态效果直接显示静态结果。

## 实际检查与迭代

使用本机Edge 156 / Playwright，实际运行本地站点。第一轮采集1440×900与390×844首屏、三段后续场景五个进度、手机全页、两个详情页与结尾；实际查看首屏、蓝色场、Web中点、结尾和手机详情截图。

第二轮连续截图取样文件到达过程，并复核1280×720、1440×900、390×844字体加载状态。发现新字体让矮屏首屏底部超出18px，以及手机详情封面CONTENT被裁切。调整矮屏英文尺寸、详情封面流式字号后再次截图，最终首屏底部分别为720/900/844px，无横向溢出，字体状态均为loaded，详情封面完整。

检查附件保存在本轮visualizations目录：refine-round1-*、refine-motion-review.png、refine-verified-1280.png、refine-verified-1440.png、refine-verified-390.png、refine-verified-case.png。连续截图含采集开销，不把标注时间当作原始视频帧率或真实设备帧率。
