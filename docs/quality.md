# 质量检查记录

检查日期：2026-10-28。环境为本地 Edge 无头浏览器与 Playwright 1.62.1，axe-core Playwright 适配器 4.14.0。测试使用本地临时服务器；不代表 GitHub Actions 已经运行或修改已上线。

## 无障碍

使用 axe 检查 WCAG 2 A/AA 和 2.1 A/AA 标签覆盖的规则。首页、作品集详情、文件整理助手详情的自动扫描均为 0 个违规；这不构成完整合规证明。

本轮实际修复：品牌首页链接曾设置与可见英文品牌不一致的辅助名称，影响语音操作按可见文字定位。删除多余的 `aria-label`，让名称来自可见文字。

同时验证跳到正文链接可用、单个主标题、项目详情往返、小屏无横向溢出、菜单键盘关闭、复制失败提示、无 JavaScript 及减少动态效果时的内容可访问性。新详情页无需脚本。

这些是本轮测量值，后续修改会变化。自动测试对每页设置 150 KiB 上限，防止不经意加入大资源。没有新增外部字体、图片库或运行时框架；测试库只供开发使用。

该预算只检查体积，不评估真实网速、服务器响应、LCP、INP 或 Lighthouse 分数，也不包括用户主动下载 Python 脚本的传输。真实手机、屏幕阅读器与线上网络仍需人工补测。

## 文件整理助手

8 个标准库单元测试覆盖：默认预览与取消不写入、分类移动与日志、同名目标不覆盖、预览后目标被占用、隐藏文件与链接跳过、分类目录为链接、源文件变化、目标目录不存在。

所有测试在临时目录中运行，没有整理用户真实文件。工具只提供第一层、同文件系统的逐文件移动；它没有事务回滚或自动撤销，异常时须核对实际目录和日志。

## 如何重复验证

在仓库根目录运行：

```bash
python3 scripts/check_site.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
npm test
git diff --check
```

依赖安装与浏览器选择见主 README。自动测试检查开发结果，不替代人工查看文案、真实设备体验与发布后确认。
