## 声音与编辑规则

1. **短标题有动作，正文说具体。** 标题可以留白；下一段必须回答做了什么、为什么、到哪一步。
2. **第一人称不表演。** 可以写“我在学”，少用“热爱/始终/致力于”，不以“我们工作室”自称。
3. **一段一个重心。** 章节主标题约6–12字，项目摘要约50–80字；正文允许完整解释限制，不为节奏删事实。
4. **中文讲意义，英文作索引。** 英文使用6个稳定短词组；不逐句双语复写，不在真实项目名称中硬加英文品牌。
5. **状态必须直白。** 已实现/正在学习/关注方向/计划中不换成诗化暗语。“待写”旁必须仍写“尚未实现”。
6. **不把审美变成门槛。** 菜单、复制、下载和失败提示用常用词；无需为了全新文案把它们改得难懂。
7. 本稿中的换行是构图建议；屏幕阅读器读取完整句。保留句号，不用每句感叹号。正文不全大写，不用省略号制造“深沉”。
