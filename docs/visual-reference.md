## 原创视觉系统

概念：**构想，逐步成形 / IDEAS INTO FORM**。一个切开的圆由分散到对齐，表示从探索到结构；在首屏、项目封面、联系方式和详情标题中以不同尺度复现。没有官方版权素材、外部字体、音频或运行时外部请求。

- 主色钴蓝 `#2345eb`，墨色 `#151d35`，冷白 `#f5f6f9`，浅青 `#b8f0ee`。
- 系统无衬线栈优先明确的中西文字体名称；正文 17px，元信息 13–14px，中文标题适度字重，英文展示文字紧凑排列。代码独立等宽。
- 1280px 网格、桌面 64px / 手机 20px 基准边距；主视觉允许裁切，文本与操作区域不裁切。
- 入场：标题裁切揭示 → 分片对齐 → 身份与入口；只播放一次，没有循环背景。
- 滚动：章节进入改变导航状态，项目几何展开；使用 IntersectionObserver 和 transform，不劫持滚轮。
- 悬停与键盘聚焦共享项目反馈。系统减少动态效果时完全静态；无 JS 时所有内容和导航仍可用。
