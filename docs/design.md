# Swiss editorial design upgrade

日期：2026-10-29。设计分支：`codex/swiss-editorial-redesign`。原有 `main` 提交是可恢复基线；本次不推送、不部署。

## 设计判断

原页面的技能卡片、项目和经历具有相近的视觉权重，首屏装饰占用空间，真实作品出现较晚。本次用姓名字标确立身份，将作品提前，再展开背景、技术与成长记录。保留所有真实信息、功能和区域 ID，不添加个人经历或项目成果。

## 视觉系统

- 纸色 `#f3f1eb`、墨黑 `#191919`、瑞士红 `#b92a20`，正文辅助色 `#57564f`。
- 使用系统无衬线字体与少量等宽索引，不下载外部字体或图片。
- 内容最大宽度 1280px；桌面两侧留白、非对称列网格，手机单列。
- 项目用数字、细线和文字组成编辑式列表；已完成作品在前，计划项目在后并降低数字权重。
- 首屏短暂入场、项目悬停轻微位移、滚动淡入；支持系统减少动画偏好及键盘焦点。
- 两个详情页共用同一视觉系统，继续使用可直接刷新的根目录 HTML 路径。

## 实际视觉验证

本地 Edge / Playwright，在 1440×900 和 390×844 对首页、作品集详情、工具详情分别截图；截图不进入公开仓库。

第一轮：检查大字标、项目排序、段落行宽与详情页。发现手机字标偏小、详情页导航过高、计划项目与正式作品权重太接近。

第二轮：手机字标从 82px 提升到 105.3px（390px 视口），详情导航改成单行，计划项目数字改为较小的灰色；导航顺序与内容顺序同步。重新检查六组页面截图，无页面横向溢出。

现有静态检查、8 项 Python 测试和 6 项浏览器测试执行结果均记录在交付中。浏览器测试包含三页 axe 扫描与体积预算，而非单纯截图判断。

## 仍需人工补充

参考附件在本次环境中无法读取，因此未声称复刻附件。当前无需补充身份信息即可使用；学生信息管理系统仍标记为计划项目。真实手机、读屏软件和不同系统中文字体效果仍需人工补测。

## 字体协调性修订

根据用户反馈，进一步修正英文姓名过大、中文标题偏细、等宽标签过多和说明字号偏小的问题。参考 [Swiss Typefaces Suisse](https://www.swisstypefaces.com/fonts/suisse/) 的屏幕阅读与字族层级设计，以及 [Pentagram Typography](https://www.pentagram.com/typography) 的一致性表达。参考不意味着加载或购买对应商业字体。

使用统一的系统无衬线字体栈，等宽文字仅保留在代码示例中；正文 16–17px，导航与按钮 14px，辅助信息主要为 12–14px。中文标题采用 600 字重，减小负字距，桌面姓名字标从 285px 缩为 238px，详情页大标题从 76px 缩为 64px。

重新截图检查三个页面的 1440×900 和 390×844 渲染，并通过全部 6 项浏览器检查。三页 axe 扫描均无违规，资源合计分别为 36,271、20,622、20,508 bytes。没有提交、推送或部署本轮改动。

## 首页架构重新设计

以上为前两轮设计过程。根据用户进一步授权，当前首页已不再沿用原来的五段式结构：

1. 分栏首屏：左侧以开发方向为主标题，右侧红色身份面板呈现姓名、学校与当前方向。
2. 作品区：两个真实作品并排展示，封面直接表达项目内容；计划项目单独降低权重，保留分类筛选及功能说明。
3. 个人档案：将个人介绍、教育背景、技能整合为一个区域；完整学习记录通过原生 details 展开。
4. 深色联系区域：集中呈现邮箱、复制入口与 GitHub。

新增 home.css 管理首页构图，共享样式与详情页留在 style.css。保留旧区域锚点、基础信息和原有业务交互，没有增加未经确认的个人事实。

第一轮 1440×900 / 390×844 截图发现手机项目封面继承了旧横排样式，导致文字溢出。修正为纵向封面后完成第二轮截图，三个页面均无横向溢出。现有 6 项浏览器测试、8 项 Python 测试及静态检查全部通过；axe 扫描无违规。首页及资源约 41 KB。本轮仅本地修改，未提交、推送或部署。
