## 下一轮阶段与完成条件

### 1. 保存可恢复状态，确认内容来源

当前分支为 `codex/visual-motion-system`，有上一轮未提交代码；已发布基线为 `9fc5762`。下一轮先核对实际Git状态，妥善保存已有工作后从明确恢复点开发，不使用reset覆盖已有改动。按用户当时授权决定是否做本地提交，提交不等于推送/部署。

锁定本轮批准的方向与文案版本。学校、联系方式、项目链接、C++计划状态和Python限制单独列为保留项。没有新项目事实时不补造案例。

**产出**：批准稿与恢复点清楚；既有未提交工作可恢复。

### 2. 先做静态艺术指导，不先铺动画

重排首页与详情页，建立选定方向的颜色、字体、网格和开口框语法。优先看1440×900、390×844的静态首屏、两个项目和联系区域。正文、标题、技术、状态、链接先完整存在；不依赖一张PV截图作为背景获得效果。

**产出**：关闭全部动画也足以辨认主题；中文字号与换行、密度与对齐已成立。无法识别身份或找到项目时，不用动效掩盖。

### 3. 一个小样验证技术路线

只做S01或S04的一个可逆进度样片，在隔离预览中验证，不一口气铺完六场。

候选GSAP core＋ScrollTrigger须固定版本、自托管相对路径并保留许可；实现前核对当时官方文档/许可。只使用必要模块，不加入ScrollSmoother、3D或字符拆分依赖。若资源预算或移动体验不通过，使用CSS时间轴与原生JS/WAAPI组合，保留同一分镜，不降低成“一次淡入”。

**产出**：0/25/50/75/100%及倒退状态吻合；停滚停画，直接拖动滚动条也正确；技术选型有实际资源与帧耗证据。

### 4. 连成六场，保留正常操作

按S01–S06建立局部时间轴和装饰层，不建立一个巨大的全站fixed舞台。两处短pin额外滚动合计目标1.30V、上限1.50V；手机取消占位。普通内容自然滚动，段落和按钮不参加字形裁切/视窗缩放。

保留筛选与details：隐藏场景前清理其时间轴/占位，DOM变化后重建测量。锚点、刷新、返回项目和联系入口直接到真实标题；同一进度状态不能依赖之前是否经过某个onEnter。

**产出**：有可描述的章间graphic match；上/下滚都成立；操作不用等演出。

### 5. 做响应式动效，而非缩小桌面

单独处理390px手机、768px平板、窄桌面、矮屏和缩放。减少动态效果与无JS模式回到完整静态布局，并移除pin空白。移动地址栏变化、横竖屏、窗口resize、字体就绪后重测，避免每次变化从头播放。

**产出**：小屏仍有主题与阅读层级，演示没有遮挡身份、项目摘要、状态和触控按钮。

### 6. 至少两轮有依据的审查

| 检查 | 具体方法 | 失败条件 |
| --- | --- | --- |
| 静态构图 | 三页1440×900与390×844，全页与局部 | 图形碰到文字、单字孤行、正文偏小、关键状态低对比 |
| Scroll-driven | S01/S04各采0/25/50/75/100%，正反向两组；S02/S03/S05/S06各检查进入/中段/退出 | 同一p得到不同构图；上滚不回退；停住后仍长时间追赶 |

| 动态性能 | 桌面与手机模拟记录Performance，检查长任务、布局抖动、合成层 | 持续布局测量、无必要全屏滤镜、肉眼卡顿未解释 |

| 降级 | 禁JS、JS加载失败、减少动态效果 | 看不到正文、仍有无意义长空白、链接不可用 |
| 内容真实性 | 对照F01–F13逐项看最终文案 | 把方向写成熟练技能，把计划或演示写成实际成果 |

第一轮记录具体缺陷与对应修订，第二轮重新截图核实修订，不仅凭测试绿灯评审。若没有真实设备或Safari，明确保留验证缺口；浏览器模拟不可称“真机通过”。

### 7. 执行现有检查，再交付本地结果

保留并按改动更新已有测试，尤其是标签重命名后的语义导航，以及新增的scrub/占位清理测试。不得只删除旧断言来获得通过。

现有命令：

```bash
python3 scripts/check_site.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
npm test
git diff --check
```

当前测试使用**解码后资源总量150KiB**预算。不能拿gzip体积与此比较；引入GSAP前先测实际新增体积，若超预算，先减少资源或选择原生实现，不静默提高测试阈值。无障碍除减少动态效果模式外，还需采查正常动效的关键状态，不能只扫描静态终态。

**产出**：最终文件差异、两轮视觉证据、实际测试结果、已知不足、内容待补清单。未获后续明确授权时只交付本地结果，不自动推送、合并或部署。
