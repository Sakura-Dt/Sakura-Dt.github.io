## 设计目标与取舍

参考研究先于页面实现，详见 [Visual Reference Analysis](./visual-reference.md)。实际观看范围为两个官方 PV 的前 30 秒试看，并非完整影片。已记录代表时间点与无法确认的内容，未把官方画面、角色、标识、音频或截图加入网站。

主题「构想，逐步成形」连接学习与开发过程：切分圆表达探索与组织，分片结构呼应项目封面。钴蓝建立身份，浅青形成强调，冷白用于阅读，墨色用于收束。大标题承担展示，中文段落承担具体信息；保留可读字号，不让装饰决定正文可见性。

首页重新安排成整体式蓝色主视觉、真实作品、个人介绍与技能、学习记录、联系区域。详情页用共通标识、封面词汇与颜色延续视觉身份，在正文部分降低动态与图形密度。项目状态、下载、筛选、复制、时间线和旧锚点保留。

## 代码职责

- `index.html`：身份、方向与作品的语义化结构；原创建模式 SVG 和 CSS 封面不承载必要信息，使用 aria-hidden。
- `assets/css/style.css`：共享颜色、字体、间距和缓动 tokens，导航、控件、详情与减少动态效果规则。
- `assets/css/home.css`：首屏标题裁切、分片图形入场、项目构图展开、悬停与聚焦反馈、手机和平板构图。
- `assets/js/main.js`：保留原有操作；IntersectionObserver 增强装饰图形和当前章节，不监听持续滚动、不拦截浏览器滚动。
- 两个详情 HTML、favicon、README 与测试随实际实现同步。

入场以 850ms 裁切和分片对齐为主，悬停与按钮为短反馈，没有循环动画、加载门槛或自动音频。减少动态效果时完全静态；偏好在浏览中变更也立即生效。无 JavaScript 时正文、导航、原生详情和链接保留；手机导航正常占据文档流，避免挡住锚点。

## 真实浏览器审查

使用本机 Edge / Playwright 临时静态服务器，完成旧版本基线及两轮新版本检查。三页分别在 **1440×900、390×844** 检查首屏与全页；额外检查项目详情展开、学习记录展开和手机菜单。截图保存在仓库之外，没有加入发布文件。

第一轮发现：

1. 主视觉几何与标题末尾或手机第一行相接，影响笔画辨识。缩小并重新定位圆形，手机独立构图。
2. 手机详情标题最后一个字单独换行。根据语义标记两段标题，并在手机断行；桌面仍连续阅读。
3. 详情封面的大图形位于文字后方，对比不足。降低背景图形权重，使文字层清晰。
4. axe 检测首页标识可见文字与 aria-label 不一致。移除多余标签，使用可见名称。

第二轮再次查看全部三页首屏、正文、联系方式及展开状态，以上问题修复；三页在两个目标视口均无横向溢出或浏览器脚本错误。另补查 768px 平板，调整中间断点的图形尺寸与位置，使其避开学校说明和第二行标题。字体通过浏览器 CDP 核对：当前 Windows 环境实际使用 Arial / Noto Sans SC，与设计的无衬线系统一致。
