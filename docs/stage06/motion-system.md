## Motion Design System

实际代码没有GSAP、ScrollTrigger或Canvas。本次沿用原生滚动、CSS固定定位与SVG，统一到 `assets/js/motion.js`。

| 项目 | 规则 |
| --- | --- |
| 进度 | 场景内0–1归一化进度；滚动由实际位置计算，手机步骤由明确的状态目标计算 |
| 时间轴 | `SAKURA_MOTION.score` 集中管理各场景行程与关键停止点 |
| 缓动 | 共用五次平滑曲线 `6t⁵−15t⁴+10t³`，两端速度与加速度归零 |
| 跟随 | 同一指数响应；桌面62ms、手机48ms，单次时间增量最多50ms |
| 收敛 | 误差低于0.00005时落到目标值，随后停止请求帧 |
| 主运动 | 图形先组织空间，文字在阅读区形成后出现；不统一改成旋转/缩放模板 |
| 辅助运动 | 标记、分隔线和索引服从主运动；章节接缝使用同一缓动，不新增固定区间 |
| 遮罩 | 文本使用inset裁切；连续底面用polygon；开场折面继续用SVG共形裁切 |
| 退出 | 章节稳定在自己的终态，随后通过原生滚动离开；避免整章淡出与淡入 |
| 反向 | 滚动场景仍由同一进度函数还原；手机项目按钮按同一停止点逆序返回 |

各场景保留自己的内部阶段和错峰关系：开场重视展开与揭示，Python重视分类与确认，Web重视比例与布局，结尾重视收拢和联系方式。

## 五处连接的设计目的

| 连接 | 实施 | 阅读目的 |
| --- | --- | --- |
| 首页 → 本人 | 保留同一个六面图形形成蓝色信息结构的演出 | 从主题进入真实身份与学习方向 |
| 本人 → Python | 蓝色信息底面延伸为原生滚动接缝，收成作品索引折线 | 给身份介绍一个结束，并在作品索引停下来选择阅读 |
| Python → Web | 整理结果的蓝色延续到实现说明；蓝色平面再收向深色画面中的橙红测量线 | 先读清工具的能力与限制，再转入空间与布局问题 |
| Web → 学习方向 | Web结束后进入米白说明与详情入口，再接同色的学习章节 | 以静止阅读区形成节奏停顿，避免连续固定演出 |
| 学习方向 → 联系 | 保留六个面的铺展、收拢与邮箱分隔线形成过程，采用统一时钟 | 在简洁、可操作的联系画面收束 |

两个新增接缝分别承担颜色/折线延续与平面/测量线匹配。它们是独立SVG的视觉衔接，不把两个原有章节伪装成一个共享DOM对象。它们随原生滚动变形，不固定、不接管滚轮、不遮挡文字。筛选为单个项目时，项目之间的接缝隐藏，避免孤立转场。

## 调度、测量与生命周期

每个页面文档只有一个被动scroll监听器与一个共享RAF队列。场景以实际DOM元素作为队列键，同一帧同一场景只执行一次。持续运动与交互后的布局等待均使用这个队列。

- 布局按页面顺序计算，先形成前一章节的高度，再测量后一章节的位置。
- resize与外部内容高度变化按120ms合并；字体就绪、演示就绪、筛选、阅读披露和模式变化显式触发布局。
- 滚动只读取缓存的章节边界、页面行程与当前滚动位置，不在每个滚动事件里重新测量所有DOM。
- 视口外场景只在跨过边界时更新端点；手机项目步骤不因页面滚动重复绘制。
- 阅读进度条复用同一调度，页面高度只在布局阶段缓存。
- 监听器由AbortController拥有；章节移除时清理所属监听与待执行帧，并刷新后续章节。
- 普通页面离开时销毁调度器、监听器、定时器、观察器和待执行队列；布局JSON请求使用同一可中止信号。
- 页面暂停时取消当前RAF但保留待恢复队列；返回时重新读取模式和布局。测试同时验证暂停时新增的任务能在恢复后执行。
- iframe等待真实首页标记与load，不把about:blank当成已准备页面；字体完成后才缓存源节点。
- 只观察头部与原生阅读区域的高度变化，嵌入的真实首页演示不启动尺寸观察，避免自身插值触发刷新循环。

`SAKURA_MOTION.stats()` 只用于调试与测试，页面没有新增调试界面。

## 必要视觉修正与降级

第二轮审查发现手机Web末态的说明与按钮空间不足。仅调整外部预览窗口的显示比例，为说明和点击区域留出空间；内部真实手机页面仍是390×844的实测构图，字体与布局没有被替换。

系统或站内减少动效、节省流量模式、较矮屏幕继续提供静态阅读。Python默认显示完整整理结果；Web提供即时布局切换；身份、学习状态、项目详情和联系信息保留。无JavaScript时仍有内容、链接与分类结果。

新增的手机操作提示所需中文字符已补齐到原有同源字体子集，字体家族、许可与权重系统不变。
