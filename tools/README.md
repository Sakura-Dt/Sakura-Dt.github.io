# 文件整理助手

Python 3.12 命令行练习项目，无第三方依赖。扫描目标目录的第一层文件，按扩展名分到 `images`、`documents`、`archives`、`media` 或 `others`。

从仓库根目录运行，先使用自己创建的测试目录：

```bash
python3 tools/file_organizer.py ./sample-files
```

默认只预览，不创建目录、日志或移动文件。确认预览符合预期后运行：

```bash
python3 tools/file_organizer.py ./sample-files --apply
```

输入大写 `MOVE` 才执行，其他输入会取消。Windows 可将 `python3` 换成 `py`。

- 仅处理第一层普通文件；跳过隐藏文件、符号链接和子目录。
- 不覆盖同名目标；分类目录异常或为符号链接时跳过。
- 文件在预览后发生变化则停止。执行期间不要在其他程序中修改目标目录。
- 移动记录写入目标目录的 `.organizer-log.jsonl`，记录时间和相对文件名。日志可能包含个人文件名，不要把真实目录或日志提交到仓库。
- 使用同一文件系统的硬链接再删除原路径，避免目标已存在时被覆盖。文件系统不支持硬链接时会报错并停止；没有跨文件系统复制模式。
- 这是逐文件执行的工具，不是事务，也没有自动撤销。中途失败时，已经完成的移动保留，请根据目录及日志核对。日志写入失败或进程异常中止时，最后一条记录可能不完整。

验证命令：`python3 -m unittest discover -s tests -p 'test_*.py' -v`。所有验证仅操作临时目录，不整理开发电脑上的实际文件。
